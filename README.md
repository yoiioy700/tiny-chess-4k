# tiny-chess-4k

[![make.fun · tiny-chess-01](https://make.fun/badge/tiny-chess-01.svg)](https://make.fun/bounty/tiny-chess-01?utm_source=github&utm_medium=readme&utm_campaign=tiny-chess-01)

A deterministic 4 KB Python chess engine: PeSTO tapered evaluation, principal-variation search with a transposition table, null-move pruning and late-move reductions, fixed node budget so replays match move for move.

## Run it

```sh
MAKEFUN_ENV_URL=<env> python3 main.py
```
